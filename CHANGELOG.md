# Changelog / 更新记录

## 0.2.1 — 2026-10-03 public release / 首次公开发布

### English

- Publish the existing JED Scoring 0.2.1 implementation as open source.
- Record the maintainer's successful Suno Studio 2 manual compatibility report.
- Include local video preview, silent reference WAV generation, explicit clip binding, Studio-following synchronization, Offset controls, Picture-in-Picture, and local audio mute.
- Include Simplified Chinese, Traditional Chinese, and English interfaces, with developer links defaulting to Bilibili.
- Add bilingual public documentation, MIT licensing, dependency notices, contribution/security guidance, and GitHub Actions verification.

This publication does not introduce a runtime feature change. Earlier local development history is not part of the initial public snapshot.
