# 隐私与权限模型

[English](privacy.md)

## 本地状态与持久化

- 所选视频内容、blob URL、文件名、时长与尺寸保留在当前侧边栏内存中。
- 参考片段选择与绑定、Offset、静音和画中画也属于会话状态。
- 界面语言保存在扩展本地存储中；仅在普通浏览器预览时回退到 localStorage。
- 关闭或重载面板后，需要重新选择视频、确认参考块并设置 Offset。当前界面不保存或恢复工程。
- 后台 service worker 在内存中保留最多 200 条诊断事件。
- 生成的静音 WAV 在拖动或下载前保留在内存中。

当前侧边栏不持久化视频内容、绝对路径、媒体指纹或参考映射。元数据读取器或预览销毁时会释放对应 blob URL。

源码中包含独立测试的 IndexedDB 工程存储与有限内容指纹辅助模块，但 0.2.1 生产侧边栏尚未接入它们，不能据此认为已提供工程保存功能。

## 从 Suno 读取的数据

仅在用户连接后，后台才向激活的 `https://suno.com/studio` 标签页附着 Chrome DevTools Protocol。语义 MAIN-world 探针读取可见播放控制区，报告工程时间、播放或暂停、拖动状态、单调序号及固定策略标识，不依赖生成的 CSS 类名或 SVG 路径。

CDP Network 收集器仅读取严格白名单内的工程、修订、版本与保存端点的请求或响应体。它验证大小、状态、编码与结构，立即提取时间、循环及安全音频块字段并释放原始数据。

Chrome 在 document_start 的 MAIN world 中直接运行独立观察器，包装页面已有的 Fetch，仅处理允许的来源、路径与方法，克隆成功 GET 响应或读取现有 save-project 字符串请求体，验证后通过带版本同源消息传递受限字段。它不注入 script 标签、不动态导入或访问扩展 API，不主动发请求、不修改请求，也不读取请求头。

扩展不会检查 Suno Cookie、本地或会话存储、个人资料、密码、访问令牌、API 密钥、认证请求头或账号数据。

## 网络与上传

扩展不会上传原视频或原声，也不收集遥测。开发者链接只在你主动点击后打开外部站点。

本地读取视频元数据后，生成相同时长、44.1 kHz、单声道、16 位 PCM 的全零 WAV。只有真实拖动或点击下载才会提供此文件；扩展不调用 Suno 上传 API。

拖动数据只包含生成的 WAV，不含原视频 File、视频内容、原声、绝对路径或凭据。文件名由原视频名称生成；如不希望向 Suno 透露名称，可先下载改名后再导入。

直接拖动无效时，可下载 WAV 并从浏览器下载气泡拖入；无需 downloads 权限或遍历文件夹。

## 诊断导出

**复制诊断摘要**会复制含 `schemaVersion: 1` 和 `entries` 数组的 JSON，数据来自后台最多 200 条的内存缓冲区。事件包含时间戳、类别、事件或错误代码，以及数量、布尔值、会话代次、观察时间和播放探针策略等受限信息。

缓冲区拒绝敏感字段名或值，包括 URL、路径、疑似认证值、工程标识、提示词与歌词。诊断不包含原始工程响应、媒体、文件名、指纹或凭据。分享前请检查摘要内容。

独立的 `src/diagnostics/export.ts` 辅助模块已有测试，但不是当前界面实际使用的导出实现。

## 清单权限

| 权限 | 当前用途 |
| --- | --- |
| `storage` | 保存界面语言选择。 |
| `sidePanel` | 展示扩展界面。 |
| `debugger` | 用户连接 Studio 后，通过 CDP 观察允许范围内的工程与播放状态。 |
| `tabs` | 附着前验证当前 Studio 标签页。 |
| `https://suno.com/*` | 在明确的 Suno HTTPS 主机运行内容脚本。 |

不申请 scripting、webRequest、cookies、任意主机访问、downloads、麦克风或摄像头权限。debugger 是较强的浏览器能力，代码将其使用限制在上述观察流程；Chrome 可能显示正常的调试提示条。
