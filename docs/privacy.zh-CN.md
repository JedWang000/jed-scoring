# 隐私与权限模型

[English](privacy.md)

## 保留在本机的数据

- 所选视频内容与 blob URL，以及侧边栏打开期间的文件名。
- 最多前 64 KiB 内容的 SHA-256 前 24 位十六进制指纹、文件大小和媒体类型，用于重新授权检查。
- 视频时长、尺寸、可选帧率与音频元数据、参考绑定、Offset 及偏好。
- 最多 500 条内存诊断事件。
- 拖动或下载前保留在内存中的静音 WAV。
- 视频播放、静音与画中画状态；这些状态不会发送给 Suno。

IndexedDB 不保存绝对路径或视频内容。元数据读取或预览结束后释放对应 blob URL。

## 从 Suno 读取的数据

仅在用户连接后，后台才向激活的 `https://suno.com/studio` 标签页附着 Chrome DevTools Protocol。语义探针读取可见播放控制区，只报告工程时间、播放或暂停、拖动状态、单调序号与固定策略标识，不依赖生成的 CSS 类名或 SVG 路径。

CDP Network 收集器仅读取严格白名单内的工程、修订、版本与保存端点的请求或响应体。它验证大小、状态、编码与结构，立即提取时间、循环及安全音频块字段并释放原始数据。诊断不含原始响应、URL、工程标识、媒体地址、歌词或提示词。

Chrome 在 document_start 的 MAIN world 中直接运行独立观察器，无需注入 script 标签、动态导入或访问扩展 API。观察器包装页面现有 Fetch，只针对允许的来源、路径与方法克隆成功的 GET 响应，或读取页面已有的 save-project 字符串请求体。校验后通过带版本的同源消息传递受限字段，不发请求、不修改请求，也不读取请求头。

扩展不会检查 Suno Cookie、本地或会话存储、个人资料、密码、访问令牌、API 密钥、认证请求头或账号数据。

## 网络与上传

扩展不会上传所选视频及原声，也不收集遥测。视频元数据在本机读取后，生成相同时长、44.1 kHz、单声道、16 位 PCM 的全零 WAV。只有用户真实拖动或点击下载才会向外提供此文件；扩展不调用 Suno 上传 API。

拖动数据仅包含生成的 WAV，不含原视频 File、视频内容、原声、绝对路径或凭据。文件名由原视频名称生成；如果不希望向 Suno 透露名称，可先下载改名后再导入。

直接拖动不被接受时，可点击“下载静音 WAV”并从浏览器下载气泡拖入。无需 downloads 权限或遍历文件夹。开发者链接只会在你主动点击时打开外部站点。

## 诊断导出

允许字段仅包含适配器健康状态、数值时间和漂移、绑定状态、选择器策略版本及错误代码。排除文件名、指纹、媒体内容、浏览器存储和认证数据。提交反馈前仍应检查分享内容。

## 清单权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 本地工程与偏好持久化。 |
| `sidePanel` | 扩展界面。 |
| `debugger` | 观察用户选定的 Studio 标签页中允许范围内的工程与播放状态。 |
| `tabs` | 附着前验证当前标签页确为 Studio 页面。 |
| `https://suno.com/*` | 在明确的 Suno HTTPS 主机运行内容脚本。 |

不申请 scripting、webRequest、cookies、全站访问、downloads、麦克风或摄像头权限。debugger 是浏览器授予的较强能力，代码将其使用限制在上述观察流程；Chrome 可能显示调试提示条。
