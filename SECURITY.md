# Security policy / 安全政策

## English

Security fixes are considered for the latest published release. Report suspected vulnerabilities privately using GitHub **Security → Report a vulnerability** if available, or contact [the developer](https://b23.tv/iNOah8D) to arrange a private channel. Do not open a public issue containing exploit details or private data before coordination.

Include the affected version, minimal reproduction, impact, and a proposed fix if known. Do not send Suno cookies, passwords, tokens, raw project responses, original videos/audio, or browser profiles. Redact diagnostics and screenshots before sharing. No guaranteed response SLA is offered.

## 中文

安全修复面向最新发布版本。发现疑似漏洞，请优先通过 GitHub **Security → Report a vulnerability**（如可用）私下反馈，或[联系开发者](https://b23.tv/iNOah8D)约定私密渠道。协商前不要在公开 Issue 中披露利用细节或私人数据。

请提供受影响版本、最小复现步骤、影响范围及已知修复建议。不要发送 Suno Cookie、密码、令牌、原始工程响应、原视频音频或浏览器配置；分享前请脱敏诊断与截图。本项目不承诺固定响应时限。
